# Riley’s Fantasy AI Luxe 6.5 — Gameplay and Settings Update

This version retains the existing website and adds settings panels to both games. Castle Siege adds spacebar jump, gravity, more architectural detail, zombies alongside vampires, and mouse sensitivity. Midnight Kart adds revised acceleration, drift handling, kart lean, and additional themed roadside scenery. Both games have remappable keyboard controls, graphics-quality and effects-volume preferences stored in localStorage.

## Install
Upload all extracted files to the existing GitHub Pages repository, replacing matching files. Keep the folder structure flat. The Three.js library loads from a CDN, so games need internet.

## Limitations
These remain stylised procedural 3D browser prototypes. They do not use photorealistic character models, motion-captured animation, advanced physics, or AAA-quality art assets. Effects-volume is saved as a preference, but the games do not yet contain a sound engine. Keybinding remapping affects physical keyboard events; touchscreen buttons remain fixed. Performance varies by phone.
