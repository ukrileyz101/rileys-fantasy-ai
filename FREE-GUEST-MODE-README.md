# Riley's Fantasy AI LUXE 10.0 — Free Guest Mode

This version removes the account popup, Supabase authentication scripts, cloud upload/restore controls, and Supabase setup files. No sign-in is required. The existing AI backend setting is retained, but actual AI availability depends on that external service.

## Publishing
Extract this ZIP and upload its **contents** (not the ZIP or an enclosing folder) to the root of your GitHub Pages repository. Commit changes and wait for deployment. Refresh with Ctrl+Shift+R.

## Important
Stories and other creations save in the browser on the current device. They do not sync across devices. Clearing site data can erase them. Export/back up important data before switching devices or clearing storage.

This update does not delete the Supabase project or Resend account on those services. They can be left unused or deleted separately in their dashboards if desired.
