# Advanced Cover Studio — LUXE 10.0

Creative Studio → Cover Studio. Add title, author, subtitle, colour, font, text alignment, and optional uploaded artwork. Live preview shows the result. Save a cover to the local gallery, edit or delete it, and export it as a 720×1080 PNG.

Existing cover cards from earlier builds remain in the gallery and can be edited. The app stores data locally in your browser; backup your projects before changing browsers or clearing data.

Testing: upload an image, edit fields, save, export PNG, refresh, edit the saved cover.
